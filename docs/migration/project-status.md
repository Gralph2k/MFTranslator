   править руками, не удалять. Бэкап перед каждым деплоем: `deploy/backup.sh`
   (последний — `bot-2026-11-10_1131.db`).
4. **Правило «изменение = деплой».** Любое изменение кода/сценариев/конфигурации
   деплоится и перезапускает бота; порядок — §7 `DEPLOY.md` (тесты → бэкап → архив →
   `chown`/`chmod` → `pip install -e .` → `systemctl restart` → `is-active` + журнал
   без `Traceback`/`Conflict`). «Локально работает» ничего не доказывает.
5. **Сервер в CET, а PROGRESS/переписка — в МСК.** Все серверные метки (`journalctl`,
   cron, `systemctl`) — UTC+1; к МСК прибавлять 2 часа зимой. Эта же ловушка уже
   дала ошибку в PROGRESS (§9.1).
6. **Второй бот с тем же токеном.** Прод работает long polling с боевым токеном;
   запуск локального бота (`run-bot.cmd`) с тем же токеном даст
   `Conflict: terminated by other getUpdates` на одном из экземпляров. Локально —
   только `bot.cli --provider demo` или отдельный тестовый токен.
7. **Два источника правил.** `AGENTS.md` — канон, `CLAUDE.md` его импортирует
   (`@AGENTS.md`). Правила менять в `AGENTS.md`, иначе файлы разойдутся. Скил
   `writing-scenarios` — две копии (`.dsh/skills/` и `.claude/skills/`), сейчас
   побайтно одинаковы; при правке синхронизировать.
8. **Фото Евы в движении.** Кадры генерируются во время подготовки пакета; версии
   `eva_base.jpg` на сервере и локально разные. Перед деплоем убедиться, что
   утверждённые файлы на месте; не деплоить недоделанный набор.
9. **Особенности среды разработки** (из [PROGRESS.md](../../PROGRESS.md) §«Важные
   особенности среды»): сетевые проверки — только через Python (curl/PowerShell
   ломаются на TLS в песочнице); `uv` не пишет кэш в `%LOCALAPPDATA%` — задавать
   `$env:UV_CACHE_DIR="$PWD\.uv-cache"` (в `.claude/settings.json` уже есть);
   `%TEMP%` закрыт — тесты пишут в `.tmp/`, кэш pytest отключён; длинные ответы
   DeepSeek иногда рвутся («Messages transport failed») — держать дампы короткими.
10. **Нет CI и lock-файла.** Проверка только ручная (`pytest`, demo-прогон),

    на VPS 3.12.16 — не использовать синтаксис 3.13 без проверки на 3.12.
11. **Пакет передачи — не код.** `CLAUDE.md`, `.claude/`, `docs/migration/` не входят
    в боевой архив и не влияют на бота; деплоить их не нужно. При этом ссылки внутри
    пакета должны указывать на существующие файлы — при финализации проверить
    (файлы создавались параллельно, часть появилась уже после первой версии README).
12. **`.tmp/` ~4 213 каталогов** — мусор от тестов, gitignored, на проект не влияет;
