# Состояние проекта

Файл для продолжения работы после обрыва связи или в новой сессии.

## Что делаем

Telegram-бот — тренажёр эмоционального интеллекта для русскоязычных мужчин 25–45 в отношениях.
MVP: один сценарий «Пятничный вечер», персонаж Аня с внутренним состоянием,
диалог через DeepSeek API, разбор после диалога по рубрике.

## Статус: живой диалог проверен, остался доступ к Telegram

Проверено вживую 18.10.2026 (DeepSeek, VPN включён):

- Кризисный ход останавливает сцену и печатает сообщение с 112.
- `pytest` — 34 passed. `bot.doctor`: DeepSeek OK, Telegram — ConnectTimeout (VPN не
  маршрутизирует Telegram: внешний IP 62.217.184.234, TCP 443 не открывается).

Починено по ходу:

- Состояние не обновлялось в реальном боте: DeepSeek в JSON-режиме стабильно отдавал
  пустую строку (замер: 8 из 8), а клиент после пустоты уходил в обычный текст.
  Теперь два запроса на ход: реплика — текстом, состояние — коротким JSON-запросом.
  Проверено вживую: openness 0.15 → 0.2 → 0.3, заметки отражают ход разговора.
- Пустые ответы DeepSeek в JSON-режиме: при пустом `content` клиент убирает
  `response_format` и повторяет; если и это не помогло — добавляет прямое требование
  вернуть непустой JSON.
- `CERTIFICATE_VERIFY_FAILED` из-за VPN/антивируса: httpx доверяет хранилищу
  Windows через `truststore` (`bot/tls.py`).
- Демо-режим различает реплику персонажа, оценку состояния и запрос на разбор.
- Слой безопасности подключён к движку, CLI и Telegram-хендлеру (`bot/safety.py`).
- Приветствие бота: как играть, что можно описывать действия, сколько сообщений
  и подсказка на первый ход.

Осталось для запуска в Telegram: маршрут до `api.telegram.org` — VPN в режиме полного
туннеля, `TELEGRAM_PROXY` или VPS. Код к любому варианту готов.

## Решения, которые уже приняты

- Формат MVP: один сценарий с полноценным разбором (не свободный чат).
- Модель: DeepSeek API, OpenAI-совместимый `/chat/completions`, JSON-режим.
- Аудитория: русскоязычные мужчины 25–45 в отношениях.
- Персонаж — явный симулятор: в описании бота и в первом сообщении сказано, что это тренажёр.
- Педагогика: навык — замечать, спрашивать, признавать чувство, не решать за другого;
  механика не вознаграждает «угадай желание».
- Состояние: trust/openness/energy в 0..1, обновляется моделью, зажимается в коде;
  персонаж не оттаивает от одной фразы.

## Важные особенности среды

- Сетевые проверки делать только через Python: `curl` и PowerShell в этой системе
  ломаются на TLS (`SEC_E_NO_CREDENTIALS` в песочнице, `CRYPT_E_NO_REVOCATION_CHECK` вне её).
  Python ходит в `api.deepseek.com` нормально.
- `uv` не может писать в свой кэш в `%LOCALAPPDATA%`: перед запуском задавать
  `$env:UV_CACHE_DIR='C:\Projects\MFTranslator\.uv-cache'`.
- `%TEMP%` закрыт песочницей: тесты создают файлы в `.tmp/` внутри проекта,
  кэш pytest отключён в `pyproject.toml`.
- Каталог `.tmp/pytest` остался от неудачного прогона и не удаляется из-за
  запрета на удаление вложенных файлов; безвреден, можно удалить вне песочницы.
- Обрывы «DeepSeek Messages transport failed» повторяются на длинных ходах:
  держать вывод команд коротким, большие дампы не печатать.
