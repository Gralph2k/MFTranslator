# Контактное фото Евы для созвона

Папка сценария `eva_call` — первый созвон после переписки (`eva_message`).
На созвоне лица нет: игрок видит только экран исходящего звонка, который рисует
`bot/call_screen.py` поверх единственной картинки — `call.jpg`.

Сейчас `call.jpg` — копия эталонного портрета Евы (`eva_base.jpg` из набора
анкеты): лицо по центру, глаза в верхней трети, плечи уходят под затемнение.
Экран звонка кладёт снизу затемнение, имя, «мобильный», «Вызов…» и красную
кнопку — модель этот интерфейс не рисует и рисовать не должна.

Свой кадр для звонка (если решите сгенерировать отдельный) — в
[prompts/eva-call-date-nano-banana.md](../../../prompts/eva-call-date-nano-banana.md),
раздел «Кадр для экрана звонка». Требования те же: фотореализм, лицо крупно
и по центру, взгляд в камеру, серьга в левом ухе, низкий хвост, без текста
на картинке. После генерации просто положите файл поверх `call.jpg` — экран
перерисуется сам по mtime.

Кадров эмоций здесь нет: на созвоне лицо не показывается, эмоция живёт в голосе.
