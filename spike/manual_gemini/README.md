# Ручной прогон с игроком из Gemini

Цель — проверить, насколько сильно эхо: в автоматических прогонах и героиню, и игрока
играет DeepSeek. Здесь игрока играет **другая модель** (Gemini), поэтому её реплики
не подстроены под промпт героини.

## Порядок

1. Открой **свежий** чат Gemini (без истории) и вставь **один блок** из
   [`player_prompts.md`](../gemini/player_prompts.md) — для основного прогона это
   блок 1 (Игорь). Это всё, что игрок знает и как он себя ведёт.
2. Напиши Gemini: «Ответь своим первым сообщением ей» — получи реплику.
3. В терминале (корень проекта, лучше venv — в глобальном Python нет `truststore`):
   `.\.venv\Scripts\python.exe -m bot.cli --provider deepseek --scenario first_message`
4. Вставь реплику игрока в терминал, получи ответ героини.
5. Скопируй в чат Gemini **только текст её ответа** в виде `Она: «…»`.
6. Повторяй 4–5, пока CLI не скажет `осталось ходов: 0` или пока игрок не напишет
   `<конец>`. Счётчик ходов игроку не сообщай, `[состояние: …]` не копируй.
   **Маркер `<конец>` в CLI не пересылай**: он значит «игрок закончил», а не часть
   сообщения.
7. Сохрани переписку в файл `spike/runs/manual_gemini/raw.md` в формате:

   ```
   Я: Привет. Ты лайкнула первая — это редакторский приём?
   Она: Приём, ага…
   Я: ...
   ```

8. Импортируй и оцени:

   ```
   python spike/import_transcript.py --file spike/runs/manual_gemini/raw.md
   python spike/redo_debrief.py --run spike/runs/manual_gemini --repeat 2
   ```

9. Для внешнего судьи — `spike/runs/manual_gemini/gemini_pack.md` (можно вставить в
   отдельный свежий чат Gemini).

## Правила

- Один чат — один прогон; для повторного прогона открывай новый чат.
- Не подсказывай игроку и не правь его реплики.
- Не вставляй игроку `rules_text` («это тренажёр…»), советы, состояние и счётчик ходов.
