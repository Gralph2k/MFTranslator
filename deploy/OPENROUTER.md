# Vision-модель для «Проверки анкеты»

Оценка фотографий анкеты - единственное место бота, где нужна модель «с глазами».
DeepSeek изображения не принимает, поэтому идём через отдельный vision-ключ:
годится любой OpenAI-совместимый endpoint (`POST {base}/chat/completions`,
`Authorization: Bearer`, части `image_url` с data-URL).

**Что на проде сейчас:** Z.AI (Zhipu) - `VISION_BASE_URL=https://api.z.ai/api/paas/v4`,
`VISION_MODEL=glm-4.6v`, ключ уже в серверном `.env`. Альтернатива - OpenRouter,
см. ниже.

## Вариант A: Z.AI (текущий)

1. Регистрация: https://z.ai → API-ключ в консоли. Карты РФ не принимаются.
2. `.env`: `VISION_API_KEY=<ключ>`, `VISION_BASE_URL=https://api.z.ai/api/paas/v4`,
   `VISION_MODEL=glm-4.6v`.
3. Цена: у GLM-4.6V ~¥/доллары за 1M токенов - на уровне цента на сотню
   оценок; одна оценка набора ≈ 2K входных + 0.4K выходных токенов.

## Вариант B: OpenRouter

1. Регистрация: https://openrouter.ai → Sign in (Google/GitHub).
2. Пополнить баланс: Credits → Buy credits. Минимум `$5`; для тестов хватит
   надолго (см. расчёт ниже). Карты РФ не принимаются - нужен зарубежный
   способ оплаты или крипта.
3. Ключ: https://openrouter.ai/keys → Create key. Имя любое, кредитного лимита
   на ключ не даём (расход контролирует сам баланс).
4. `.env`: `VISION_BASE_URL=https://openrouter.ai/api/v1`,
   `VISION_MODEL=google/gemini-2.5-flash-lite`.

## Проверка и цена

Пустой `VISION_API_KEY` - не ошибка: бот работает, фаза фото вежливо отвечает
«анализ не настроен». Проверить после рестарта: `/check` → прислать фото.

Одна оценка - один вызов на весь набор: 4 фото по 768px (~300 токенов каждое) +
промпт ≈ 2K входных, ~0.4K выходных. На дешёвых моделях это доли цента:
полный прогон анкеты (текст на DeepSeek + 1-3 оценки фото) - ~$0.002-0.004,
тысяча прогонов - единицы долларов.

Текст анкеты оценивает `deepseek-chat` по обычному ключу DeepSeek: ~$0.001
за итерацию, до 6 итераций на прогон.

Бесплатная альтернатива для смоук-тестов (OpenRouter): модели с суффиксом
`:free` (лимиты ~50 запросов/день при балансе < $10).

## Сменить модель

В `.env` поменять `VISION_MODEL` (например, на `google/gemini-2.5-flash` -
точнее и дороже) и перезапустить сервис. У Gemini-моделей бот задаёт
`max_tokens=2500`: у дефолтного лимита выхода разбор обрезается.
